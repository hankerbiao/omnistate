# 使用手册

开放平台控制台面向平台管理员和开发者，提供 API 访问治理、能力发现、在线调试和调用审计能力。

## 登录与用户

前端通过网关控制台 API 登录。当前内置测试用户包括：

| 用户 ID | 角色 | 说明 |
| --- | --- | --- |
| `user_admin` | `admin` | 平台管理员，拥有全部能力 |
| `user_developer` | `developer` | 开发者 |
| `user_zhaolei` | `developer` | 开发者 |

控制台请求需要携带：

```text
X-Console-Token: dev-console-token
X-Console-User-Id: user_admin
```

前端会自动注入这些请求头。

## 概览页

概览页展示今日调用量、成功率、活跃密钥、配额使用情况、近 7 日调用趋势和热门开放能力。它适合快速判断平台运行状态。

## API 密钥

API 密钥用于调用 `/api/v1/open` 开放 API。创建密钥时需要选择：

| 字段 | 说明 |
| --- | --- |
| 名称 | 便于识别用途，例如 CI 流水线集成 |
| 环境 | `live` 或 `test` |
| Scope | 可调用的权限范围 |
| 所属用户 | 密钥绑定的调用主体 |

密钥明文只在创建时返回一次，后续只展示掩码值。

## 开放能力目录

能力目录来自后端 `CAPABILITIES` 注册表。每个能力包含方法、路径、Scope、参数、处理方式和示例响应。

处理方式分为：

| Handler | 说明 |
| --- | --- |
| `proxy` | 代理到 DML 主后端指定路径 |
| `aggregate` | 聚合多个内部接口生成响应 |
| `local` | 由开放平台本地处理 |

## API 调试台

调试台用于选择能力、API Key 和参数后发起真实探测请求。后端由 `infrastructure/debug_probe.py` 处理，返回请求地址、状态码、耗时和响应体。

## 调用日志

调用日志记录请求 ID、密钥、方法、路径、状态码、延迟、网关延迟、来源 IP、错误码和诊断信息。排查集成问题时优先使用请求 ID 串联日志。

## 用户权限与配额

管理员可以为开发者设置：

| 配置 | 说明 |
| --- | --- |
| 允许能力 | 用户可授权给密钥的能力范围 |
| 月度调用上限 | 超出后拒绝开放 API 调用 |
| RPM | 每分钟请求数限制 |
| 并发数 | 同一主体最大并发调用数 |

管理员默认不受普通配额限制。
